SPUSTENI VE WINDOWS POWERSHELLU
Otevrete PowerShell v teto slozce.

  .\SPUSTIT.ps1 -Rezim kontrola

Kontrola kontrolnich souctu potrebuje jen standardni Python. K prohlizeni
hotovych obrazku, PDF a CSV neni instalace numerickeho prostredi nutna.
Pro nove vypocty je treba Python a zavislosti z requirements.txt:

  .\INSTALACE.ps1
  .\SPUSTIT.ps1 -Rezim testy
  .\SPUSTIT.ps1 -Rezim vse

Alternativne bez PowerShell skriptu:

  python -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  .\.venv\Scripts\python.exe ukazka_kpfm_D1e-15\reproduce.py

Rezim vse zopakuje navrh mist, simulaci, trenink, validacni restarty,
citlivosti, kontrolu mrizky, testy a vytvori aktualni notebook/pruvodce.
Rezim trenink pouze znovu natrénuje PINN z prilozenych mereni.
Rezim citlivosti pouze obnovi prostorove a casove citlivosti.
Volba -Python umoznuje zadat vlastni cestu k interpreteru.
Pro obnovu PDF: .\INSTALACE.ps1 -VcetnePdf, pak .\SPUSTIT.ps1 -Rezim pdf.

Vypocty zapisuji vlastni vystupy znovu. Dodany MANIFEST_SHA256.txt popisuje
puvodni predavany stav; po novem vypoctu se proto kontrolni soucty zmeni.
Samotne Python prostredi .venv neni pribalene. Overene verze knihoven jsou
uvedene v dokumentace/overene_prostredi.json.

INTERPRETACE
D je efektivni parametr difuze potencialu v homogennim modelu. Znama
pocatecni mapa, pevna Gaussova PSF a nulovy vnejsi tok jsou predpoklady.
Vysledky archivu nejsou konecnymi vysledky pripadu D = 1e-15.
